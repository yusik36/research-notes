시뮬레이션 환경 현실성

한 줄로

지금 제어기는 정답지를 보면서 시험을 치고 있다 — 환경 구성이란 제어기에게서 정답지를 빼앗고, 실제 기체가 받는 것과 같은 “흐리고 늦고 빠진” 정보만 주는 일이다.

어디에 앉는가 — 제어 이론(제어기 설계)과 별개인, 제어기와 plant 사이의 층(센서·추정·통신·구동·환경)을 채우는 물건 → 현재 구현 범위 — 무엇이 참값이고 무엇이 빠졌나 (2026-09-29 정리) · Sim-to-Real

왜 필요한가

참값 환경에서 잘 되는 제어기는 “센서가 완벽하고, 통신이 기다려 주고, 힘이 원하는 대로 나올 때” 잘 된다는 뜻밖에 안 된다. 실기체에서 무너지는 이유는 대부분 제어 법칙이 아니라 이 층에 있다. 그리고 이 층은 강의(제어 이론)에서 안 다룬다 — 따로 챙겨야 한다.

루프를 7칸으로 나누면 빠진 칸이 보인다

지연은 위상을 먹는다 — 제어 이론과 만나는 지점

지연 τ 는 이득은 그대로 두고 위상만 ωτ 만큼 깎는다.

e^{-sτ}  →  |e^{-jωτ}| = 1,   ∠e^{-jωτ} = -ωτ  [rad]

읽는 법 — 크기는 안 바뀌니 Bode 이득 선도에서는 안 보인다. 위상 선도에서만 교차 주파수 ω_c 근처가 ω_c·τ 만큼 내려가 위상 여유가 그만큼 준다. 빠른 제어기(ω_c 큼)일수록 같은 지연에 더 취약하다.

  • 이게 “환경 구성” 과 “제어 이론” 이 만나는 곳 — 환경에 지연을 넣어야 강의에서 배우는 안정 여유가 실제로 의미를 가진다

지연 0 인 환경에서 맞춘 게인은 위상 여유를 과대평가한다.

외란이 없으면 적분 제어가 왜 필요한지 시뮬레이션이 보여 주지 못한다.

plant 가 설계 모델과 같으면 자기 답안을 자기가 채점하는 것이다

  • 지금 local plant = holo plant = 같은 Delphin2 식. 제어기를 그 식으로 설계하면 모델 오차가 정확히 0
  • 실제 기체는 식과 다르다 (Delphin2 Ixx = 1.8 은 “Assumed value”)
  • 넣는 법: plant 쪽 파라미터만 흔든다 — 질량·부가질량·감쇠 ±10–30 %, 여러 번 돌려(Monte Carlo) 최악의 경우를 본다
  • RL 쪽에선 같은 걸 domain randomization 이라 부른다 → Sim-to-Real · 고전제어와 강화학습 비교의 공정한 조건

제어기용 모델과 plant 용 모델은 파일부터 분리해 둔다.

참값은 버리는 게 아니라 채점석으로 옮긴다

시뮬레이터의 유일한 특권은 정답을 안다는 것 — 제어기에서 빼되, 기록에는 남긴다.

/delphin2/truth   ← DynamicsSensor 참값    → logger · 평가 스크립트만 구독
/delphin2/imu, /dvl, /depth  ← 센서         → 추정기
/delphin2/odom    ← 추정 결과               → 제어기
  • 평가 = truth vs odom (추정 오차), truth vs 목표 (제어 오차) — 둘을 나눠야 추정 탓인지 제어 탓인지 구분된다
  • 잡음을 넣으면 매번 결과가 다르다 → 난수 seed 고정, 비교는 같은 seed 로
  • 기록은 ros2 bag 으로 남기면 나중에 추정기만 바꿔 재생할 수 있다

제어기가 truth 토픽을 구독하고 있으면 그건 아직 시뮬레이션용 제어기다 — 이걸로 점검한다.

헷갈렸던 점

”우리는 IMU 센서 노드를 쓰고 있다”

아니다. 제어기가 받는 건 DynamicsSensor — 시뮬레이터 내부 상태를 그대로 읽는 가짜 센서다. 센서 노드는 하나도 없다 (2026-09-29 확인).

”Pacing 1x 로 실시간으로 돌리니 실제 통신 환경과 같다”

아니다. 1x 는 화면 속도만 맞춘다. lockstep 이라 시뮬레이터는 여전히 제어기를 기다려 주고, 계산·통신 지연은 0 이다.

”HoloOcean 이 MSS 와 0.69 % 로 맞으니 실제 기체도 이렇게 움직인다”

아니다. 검증된 건 “HoloOcean = MSS 식” 까지. MSS 식이 실제 기체와 맞는지는 별개이고 미검증이다.

”HoloOcean 이 수중 센서에 강하니 설정만 켜면 실제 센서가 된다”

절반만 맞다. HoloOcean 이 주는 건 잡음·bias·(DVL) 거리 제한까지. 지연·결측·이상값·스케일·장착 오차·표준 메시지·타임스탬프는 우리 노드가 만들어야 한다.
