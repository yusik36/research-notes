Moment of Inertia

한 줄로

관성모멘트 I 와 관성 텐서 I_g = 회전판 질량, “돌리기 싫어하는 정도”. F = ma 의 m 자리에 앉는 물건이고, 방향마다 값이 달라서 스칼라가 아니라 3×3이다.

직진 :   F  =  m  · a
회전 :   τ  =  I  · α
              └┬┘
        m 자리에 앉는 것

어디에 앉는가 — 6-DOF Marine Craft Model 의 M 오른쪽 아래 블록. Mν̇ + C(ν)ν = τ 에서 M 아래쪽 절반이 무엇인지에 대한 답.

왜 필요한가

질량만으로는 회전 난이도를 말할 수 없기 때문.

빗자루 하나를 두 가지로 휘둘러보면 즉시 확인된다. 같은 빗자루, 같은 질량이다.

잡는 위치느낌
솔 쪽을 쥐고 휘두르기가볍게 휙휙 돈다
손잡이 끝을 쥐고 휘두르기무겁고 굼뜨다

→ 질량이 회전축에서 얼마나 멀리 퍼져 있는가가 결정한다.

같은 현상들 — 문 손잡이가 경첩 반대편에 있다 / 피겨스케이터가 팔을 오므리면 빨라진다 / 줄타기 곡예사가 긴 장대를 든다(일부러 I 를 키움) / 야구 배트를 짧게 잡으면 빠르게 휘둘러진다.

거리가 제곱으로 들어오는 이유는 두 개다

I = Σ mᵢ · rᵢ²          r = 각 조각에서 회전축까지의 수직거리

거리가 두 번 들어오고, 이유가 서로 다르다.

① 멀리 있는 조각은 더 빨리 움직여야 한다
   축에서 1 m 조각은 0.1 m/s, 20 m 조각은 2 m/s      ← 거리 한 번
② 멀리 있는 조각은 지렛대가 길다
   그 조각의 힘이 축에 만드는 토크는 거리에 비례       ← 거리 또 한 번

제곱이라 거리에 매우 민감하다. 거리 2배 → 관성 4배. 강의 Practice에서 기준점을 20 m 옮겼더니 I_zz 가 25,000 → 425,000 으로 17배가 됐다.

질량은 방향이 없지만 관성은 방향마다 다르다

질량 m  :  숫자 하나. 어느 방향으로 밀든 똑같이 저항.
관성 I  :  ★ 방향마다 다르다. 숫자 하나로는 못 적는다.

그래서 x축으로 토크를 줬는데 y축으로도 돌 수 있다.

        ⎡  Iₓ    −I_xy  −I_xz ⎤       Iₓ  = ∫(y²+z²)ρdV    ← 관성모멘트 (대각)
I_g =   ⎢ −I_xy   I_y   −I_yz ⎥       I_xy = ∫ xy ρdV       ← 관성곱  (비대각)
        ⎣ −I_xz  −I_yz   I_z  ⎦

대각선 = 관성모멘트. Iₓ = ∫(y²+z²)ρdV 에 x 성분이 없다 — x축을 중심으로 돌릴 때 x축 위에 놓인 질량은 저항하지 않는다.

비대각선 = 관성곱 = 커플링. “이 축으로 돌리면 저 축으로도 돌려고 한다”의 크기.

관성곱은 세탁기 탈수다

빨래가 골고루 퍼져 있으면 조용히 돌고, 한쪽으로 뭉치면 통이 쿵쾅거린다. 같은 질량, 같은 축, 같은 속도인데 결과가 다르다.

대칭   →  관성곱 = 0  →  z축으로 돌리면 z축으로만 돈다
비대칭 →  관성곱 ≠ 0  →  z축으로 도는데 x·y 방향 흔들림이 생긴다

자동차 휠 밸런싱이 정확히 관성곱을 0으로 만드는 작업이다. 안 하면 고속에서 핸들이 떨린다.

배는 좌우대칭(xz 평면)이라 보통 I_xy = I_yz = 0. 그런데 위아래로는 대칭이 아니다 (갑판 구조물은 위, 밸러스트는 아래) → I_xz 는 실선에서 거의 항상 0이 아니다. roll–yaw 커플링이 실제로 존재하는 이유.

BODY 좌표계를 쓰는 진짜 이유는 m 이 아니라 I 다

길이 2 m, 1 kg 연필. 길이 방향으로 돌리기는 쉽고(I ≈ 0), 수직축으로 돌리기는 어렵다(mL²/12 = 0.333).

BODY 기준 (x축 = 연필 방향):

I^b = diag( 0, 0.333, 0.333 )        ← 어떻게 돌리든 영원히 안 변한다

NED 기준:

연필이 북쪽을 향할 때 :  diag( 0, 0.333, 0.333 )
연필이 동쪽을 향할 때 :  diag( 0.333, 0, 0.333 )      ← 값이 뒤바뀐다

               ⎡ 0.167  −0.167    0   ⎤
45° 에서는    ⎢ −0.167  0.167    0   ⎥      ← 비대각 성분까지 생긴다
               ⎣   0       0    0.333 ⎦

연필은 아무것도 안 변했다. 자르지도 붙이지도 않았다. 그런데 NED 기준 숫자는 매 순간 변한다.

I^n(t) = R^n_b(t) · I^b · R^n_b(t)ᵀ         R 이 시간의 함수 → I^n 도 시간의 함수

그래서 NED로 쓰면 재앙이다:

BODY :  I^b ω̇ + (보정항)                    I^b 상수 → 미분 안 함
NED  :  d/dt(I^n ω) = I^n ω̇ + İ^n ω        ← İ^n 이라는 괴물이 추가

BODY로 쓰면 İ 항이 통째로 사라지고 대신 ω × (Iω) 하나가 붙는다. 훨씬 남는 거래. → Transport Theorem

I_g 는 새로운 물건이 아니라 S(·) 를 두 번 곱한 것

Transport Theorem 에서 배운 skew-symmetric matrix를 두 번 곱해 적분한 것이다.

I_g = − ∫ S²(r) ρ dV       ( = ∫ Sᵀ(r)S(r) ρ dV )
        V

유도 — 조각 하나의 속도는 v = ω × r = S(ω)r. 각운동량은 r × (v ρdV) 를 전부 더한 것:

h_g = ∫ S(r)S(ω)r ρdV
    = ∫ −S²(r) ω ρdV              ← S(ω)r = −S(r)ω 이용
    = [−∫S²(r)ρdV] ω              ← ω 는 배 전체가 공유 → 적분 밖으로
    = I_g · ω

−S²(r) = (rᵀr)I₃ − r rᵀ 를 전개하면 위의 3×3 성분이 그대로 나온다.

I_g 의 정체 = 각속도를 각운동량으로 바꾸는 환율표. p = mv 의 m 자리.

대칭 + 양정치라서 시뮬레이션 루프가 항상 풀린다

성질실전에서 뜻하는 것
I_g = I_gᵀ (대칭)독립 성분이 9개가 아니라 6개
I_g > 0 (양정치)ωᵀI_gω = 2×회전운동에너지 > 0 → 역행렬이 항상 존재

두 번째가 중요하다. 시뮬레이션 루프의 ν̇ = M⁻¹(τ − …) 가 항상 풀린다는 보장이 여기서 온다.

수식

회전반경 (Radii of Gyration) — MSS rbody.m 이 I 대신 받는 값.

Iₓ = m · R44²      →     R44 = √(Iₓ/m)

“질량 전부가 축에서 R만큼 떨어진 얇은 고리에 몰려 있다고 쳐도 같은 관성” 인 거리. 관성모멘트를 길이 단위로 바꿔주니 감이 온다.

평행축 정리 (Parallel-Axis Theorem) — 기준점을 CG에서 CO로 옮길 때.

I_o = I_g − m S²(r_g) = I_g + m [ (r_gᵀr_g)I₃ − r_g r_gᵀ ]

성분으로:  I_xx|CO = I_xx|CG + m(y_g² + z_g²)        ← 스칼라판  I = I_cm + m d²
           I_xy|CO = I_xy|CG + m·x_g·y_g             ← 관성곱도 같이 옮겨간다

읽는 법

  • 관성은 항상 커진다. CG에서 멀어질수록 돌리기 어려워진다. 빗자루 손잡이 끝을 잡는 것.
  • 축 방향 거리는 영향이 없다. I_xx 에 x_g 가 안 들어간다.

검산

강의 Practice: m=1000, Ixx=100000, Iyy=400000, Izz=25000

확인 항목결과맞는 이유
회전반경R44=10, R55=20, R66=5R = √(I/m)
R55 = 20 m 로 추정한 선박 크기대략 배 길이의 1/4 → 80 m급실선의 R55 ≈ 0.25L
R66 = 5 m현실적이지 않음실선은 R66 ≈ R55 ≈ 0.25L 로 둘이 비슷하다 (yaw도 pitch도 결국 배의 길이가 지배). 연습용으로 구분되게 넣은 숫자로 보임
기준점 20 m 이동 시 I_zz25,000 → 425,000 (17배)I = Σmr² 의 제곱 때문. 평행축 정리로도 확인됨
I_g 역행렬 존재 여부항상 존재양정치이므로. ν̇ = M⁻¹(…) 가 안 터진다는 보장

헷갈렸던 점

”BODY를 쓰는 건 질량을 상수로 만들기 위해서다”

질문이 맞았고 설명이 부정확했다. m 은 스칼라라 어느 좌표계에서든 1000 kg이다. BODY 좌표계를 쓰는 이유는 m 이 아니라 I 때문이다. (덧붙여 추력·유체력이 원래 BODY에 걸리고, added mass도 “어느 방향으로 움직이냐”가 배 기준이라 BODY에서만 상수다.)

”이 배의 관성모멘트는 얼마인가?”

축을 말하지 않으면 답할 수 없는 질문이다. I 는 “물체의 성질”이 아니라 “물체 + 축”의 성질이다. 같은 연필도 어느 축으로 돌리느냐에 따라 값이 완전히 다르다.

”Dyadic이라는 건 뭔가 어려운 물건이다”

겁먹을 필요 없다. r rᵀ 처럼 벡터 둘을 나란히 곱해 만든 행렬을 dyad라 부르고, 좌표계를 정하기 전의 좌표무관 표현이 dyadic이다. 좌표계를 정해 3×3 숫자판으로 적으면 그냥 inertia matrix. 강의 슬라이드 제목만 dyadic이고 실제로 쓰는 건 행렬.
