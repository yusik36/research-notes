Hydrodynamic and Restoring Forces

한 줄로

진공 속의 배(Rigid-Body Kinetics)를 물에 넣는 일. 물이 만드는 항(M_A, C_A, D)은 물에 대한 속도로, 무게·부력(g)은 자세로 계산한다.

(M_RB + M_A) ν̇_r + (C_RB + C_A)(ν_r) ν_r + D(ν_r) ν_r + g(η) = τ
η̇ = J(η) ν

어디에 앉는가 — 6-DOF Marine Craft Model 의 Mν̇ + C(ν)ν + D(ν)ν + g(η) = τ 에서 강체 몫을 뺀 나머지 전부를 채운다. → 6-DOF Marine Craft Model

왜 필요한가

Rigid-Body Kinetics 는 M_RB, C_RB 까지만 만들었다. 거기서 멈추면 배는 진공 속에서 움직인다 — 저항도, 부력도, 주변 물의 관성도 없다. 시뮬레이션 루프 ν̇ = M⁻¹(τ − Cν − Dν − g) 를 채우려면 남은 칸이 필요하다.

로드맵 — 각 항이 실제 배에서 무엇인가

항실제 현상진짜 외력인가
M_RB ν̇배 자신의 관성관성
C_RB(ν)ν선회 시 원심력·코리올리. 예: sway 방향 m·u·r❌ 회전 좌표계에서 식을 쓴 대가. 일을 안 한다
M_A ν̇가속할 때 주변 물도 밀어야 해서 더 무거운 것처럼유체 관성
C_A(ν)ν비스듬히 미끄러지면 선수를 더 돌리는 Munk 모멘트유체 압력
D(ν)ν저항 (표면 마찰·조파·와류). 저속 선형, 고속 `u
g(η)무게와 부력 — 오뚝이✅ 자세에만 의존
τ추진기·타·바람·파도✅

g(η) 만 η(자세)의 함수이고 나머지는 전부 속도·가속도의 함수다. 그래서 복원력은 heave·roll·pitch 에만 있고 surge·sway·yaw 는 되돌려 주는 힘이 없다 → 수평면은 제어기가 전부 책임진다.

M 만 알면 C 는 공짜다 — Lagrangian 파라미터화

괄호 속은 운동량이다. T = ½νᵀMν 를 속도로 미분하면 나온다.

p = ∂T/∂ν₁ = M₁₁ν₁ + M₁₂ν₂      (선운동량)
h = ∂T/∂ν₂ = M₂₁ν₁ + M₂₂ν₂      (각운동량)

C(ν) = [  0     −S(p) ]          ← MSS: C = m2c(M, nu)
       [ −S(p)  −S(h) ]
  • Kirchhoff 방정식 ṗ + ν₂×p = τ₁, ḣ + ν₂×h + ν₁×p = τ₂ 는 Transport Theorem 을 운동량에 쓴 것이다.
  • ν × p = −S(p)ν 로 뒤집는 건 H 를 만들 때 ω × r_g = −S(r_g)ω 로 뒤집은 것과 같은 수다. 변수 ν 를 곱해지는 자리로 빼기 위해서.
  • 대각 블록이 반대칭, 비대각이 서로 전치 → C = −Cᵀ 가 저절로 성립.
  • 모멘트 식의 ν₁ × p 는 질점이면 0 (p ∥ ν₁). M₁₂ ≠ 0 일 때 — CG 가 CO 에서 어긋났거나, 선체 모양 때문에 — 살아난다. 부가질량에서는 이게 Munk 모멘트다.

이 방법이 중요한 이유는 C_A 다. 부가질량의 코리올리는 Newton–Euler 로 유도하기 어렵지만 C_A = m2c(M_A, ν_r) 한 줄이면 된다.

C 행렬은 유일하지 않다 — 유일한 건 C(ν)ν 뿐

실습(강의 86쪽 조건 m=1000, r_g=[10,0,1], ν₁=[8,0.5,0.1], ν₂=[0.2,−0.3,0.2])으로 확인:

C(3.56, rbody 형태) − C(m2c)  ≠ 0      (예: 1행 = [0 0 0 200 0 −200])
C·ν 는 두 방식 모두 [−1390  920  2770  21580  −26090  −8800]ᵀ
두 행렬 모두 ‖C + Cᵀ‖ = 0
  • S(a)a = 0 이라 N(ν)ν = 0 인 행렬은 얼마든지 있다. 1행 검산: 200·p − 200·r = 200·0.2 − 200·0.2 = 0.
  • 시뮬레이션은 Cν 만 쓰니 상관없다. Lyapunov 증명(νᵀCν = 0)도 둘 다 반대칭이라 된다.

복원력 — 무게와 부력, 작용점이 달라서 모멘트가 생긴다

W = mg  (CG 에 작용)        B = ρg∇  (CB 에 작용)
g(η) = − [ f_g + f_b ; r_g × f_g + r_b × f_b ]      (BODY 로 옮긴 힘, 좌변으로 넘겨 마이너스)

성분으로 보면 φ, θ 만 나온다(위치·ψ 없음). 중성부력(W=B) + CG·CB 수직선 정렬이면:

g(η) = [0, 0, 0,  BG_z·W·cθ·sφ,  BG_z·W·sθ,  0]ᵀ        BG_z = z_g − z_b
  • 작은 각에서 g₄ ≈ (BG_z·W)·φ → 스프링 상수 BG_z·W 인 스프링.
  • MSS: g = gvect(W, B, theta, phi, r_g, r_b).

강의 슬라이드 91 에는 r_bg=CB, r_bb=CG 로 설명이 바뀌어 있다. 슬라이드 90 이 맞다.

이 식은 잠수체 용(∇ 일정). 수상선(Otter)은 기울면 잠긴 부피와 CB 가 변하므로 BG 대신 metacentric height GM 을 쓴다.

부가질량 — 물이 달라붙는 게 아니라 압력장이 가속을 방해한다

T_A = ½ νᵀ M_A ν — 주변 물의 운동에너지를 배의 속도로 적은 것. T_RB 와 모양이 같아서 Kirchhoff/m2c 를 그대로 쓸 수 있다.

  • X_u̇ = ∂X/∂u̇ : surge 가속 → surge 힘. 보통 음수 → M_A = −[…] 로 양수 행렬.
  • 방향마다 다르다: 길쭉한 배는 surge 작고 sway 큼(배 질량과 맞먹기도). 구(sphere)는 방향 무관 ½ρ∇.
  • 대칭 가정 M_A = M_Aᵀ → 독립 계수 36 → 21개. 실험값은 ½(M + Mᵀ) 로 강제 대칭화.
  • Ṁ_A = 0 : 깊은 물·이상유체 가정. 수상선은 실제로 주파수 의존 — “infinity frequency” 값을 상수로 쓴다.

Imlay 전개식(강의 99쪽)에서 대각 성분만 남기면:

X_A = X_u̇ u̇ + Z_ẇ wq − Y_v̇ vr
N_A = N_ṙ ṙ − (X_u̇ − Y_v̇) u v            ← Munk moment

|Y_v̇| ≫ |X_u̇| 이므로 u>0, v>0 이면 N_A < 0 → 선수가 흐름에서 더 비스듬해지는 쪽으로 돈다 → 방향 불안정 → 타·핀이 필요한 이유. m2c 3-DOF 분기에 M_A = diag(−X_u̇, −Y_v̇, −N_ṙ) 를 넣은 결과와 정확히 같다.

해류 — 물이 만드는 힘은 물에서 본 속도로

ν_r = ν − ν_c. 저항·부가질량은 물이 느끼는 속도만 안다(떠내려가는 배는 저항 0). 강체 관성은 땅 기준(뉴턴 법칙).

일정하고 소용돌이 없는 해류면 강체 항도 ν_r 로 바꿔 쓸 수 있다:

M_RB ν̇_c = [ −m S(ω)v_c ; −m S(r_g)S(ω)v_c ]
C_RB ν_c  = [ +m S(ω)v_c ; +m S(r_g)S(ω)v_c ]     → 합 0

배가 도는 효과가, 해류가 BODY 에서 돌아 보이는 효과를 정확히 지운다. → 해류 없는 식에 ν 대신 ν_r 만 넣으면 끝.

운동학 η̇ = J(η)ν 에는 ν_r 이 아니라 ν (땅 기준). 위치 갱신 때 해류 속도를 다시 더해야 배가 떠내려간다.

바람·파도는 우변 외력(τ_wind, τ_wave), 밸러스트 g_o 는 좌변(복원력 계열). 해류는 매질 자체가 움직이는 것이라 속도 치환, 바람·파도는 미는 힘이라 외력.

6-DOF 를 3-DOF 두 개로 — 수평면 / 수직면

roll 이 스스로 안정(BG_z > 0)하고 길쭉한 대칭 몸체면 두 평면이 거의 간섭하지 않는다.

수평면 (steering)수직면 (diving)
상태η=[x,y,ψ], ν=[u,v,r]η=[x,z,θ], ν=[u,w,q]
구동러더, 수평 쓰러스터선미 수평타, 수직 쓰러스터
복원력없음 (heave·roll·pitch 고정)있음 — (W−B), (z_gW − z_bB)sinθ

Otter USV 캡스톤 모델이 수평면 형태다.

시뮬레이션 강의 12쪽 수직면 모델 오류로 보이는 곳 — 관성행렬 비대각 m y_g 는 heave–roll 칸 값이다. heave–pitch 는 −m x_g, surge–pitch 는 m z_g. 운동학도 ψ 가 아니라 θ 로 돌려야 하고, z 가 아래 방향이라 ż = −u sinθ + w cosθ.

수식 — 시뮬레이션 루프 (강의 116쪽)

x = [ν ; η]  (12×1)
ν̇ = M⁻¹ ( τ − C(ν)ν − D(ν)ν − g(η) )
η̇ = J(η) ν,     J = [ R(Θ)  0 ; 0  T(Θ) ]        ← [J,R,T] = eulerang(phi,theta,psi)

읽는 법

  • 첫 줄은 a = F/m. 괄호 안이 알짜힘.
  • 두 식이 꼬리를 문다: 속도가 위치를 만들고(Jν), 자세가 다시 힘을 만든다(g(η)) → 동시에 적분.
  • T 의 1/cθ → θ = ±90° 발산 = Euler Angle Rates 의 gimbal lock.
  • m2c 는 M 에 선형이라 m2c(MRB+MA, nu) 로 한 번에 써도 된다(해류 있으면 C_A 에는 ν_r 이라 분리).

헷갈렸던 점

”CG 와 CB 는 xy 가 반드시 일치해야 한다”

반은 맞다. 정지 평형에서는 NED 기준으로 항상 같은 수직선 위에 있다 — 어긋나 있으면 배가 돌아서라도 맞춘다. BODY 기준으로 xy 를 일치시키는 건 필수가 아니라 설계 선택이고, 그래야 그 평형 자세가 수평이 된다. 안 맞추면 tanθ = −BG_x/BG_z 만큼 기운 채 떠 있다(trim). 강의 94쪽 식은 잘 트림된 기체를 가정한 것.

”C_RB 의 m·u·r 이 선회의 구심력이다”

구심력을 실제로 공급하는 건 물이다 — drift 로 생긴 옆방향 유체력(D, M_A 쪽). m·u·r 은 BODY 좌표계에서 그 구심 가속도가 보이는 모양일 뿐, 정상선회에서 유체력과 균형을 이룬다.

”부가질량 = 선체에 달라붙어 끌려가는 물”

딸려 가는 물 덩어리는 없다. 선체 주변 압력장이 가속을 방해하는 효과를 질량처럼 센 것 — 그래서 “가상” 질량.
