  1. 네가 생각한 구조

예를 들어 AUV에 다음과 같은 강화학습 모델이 있다고 가정해 보자.

각 모델은 자신의 임무를 수행하도록 독립적으로 학습된 상태야.

이제 그 위에 상위 강화학습 모델(Meta-Controller)을 하나 더 배치하는 거지.

여기서 중요한 건 상위 RL이 직접 추진기 명령을 생성하지 않는다는 점이야.

상위 RL은 현재 상황을 판단하고 어떤 하위 제어기를 사용하는 것이 전체 임무 수행에 유리한지 학습하는 것이 목적이야.

  1. 실제로 어떤 식으로 작동할까?

AUV가 수중 구조물 탐사 임무를 수행한다고 가정해 보자.

상황 A: 목표 지점으로 이동

상위 RL은 현재 위치와 목표 지점 사이의 거리, 주변 장애물, 해류 등을 관측해.

그리고 경로추종 RL을 선택해.

이때 하위 RL은 목표 경로를 추종하기 위한 추진기 명령을 생성하지.

상황 B: 이동 중 장애물 발견

AUV가 장애물을 발견했다고 하자.

상위 RL은 장애물까지의 거리, 상대속도, 현재 진행 방향 등을 판단해서 장애물 회피 RL로 전환할 수 있어.

장애물을 회피한 후에는 다시 경로추종 RL을 선택하는 거야.

상황 C: 목표 지점 도달 후 관측 임무 수행

AUV가 목표 지점에 도착했어.

하지만 해류 때문에 한 위치에 머무르는 것이 쉽지 않아.

이때 상위 RL은 Station Keeping RL을 선택할 수 있겠지.

여기서 네가 이전에 고민했던 수평 자세와 수직 자세 문제까지 연결할 수 있어.

예를 들어 하위 모델이 다음과 같이 나뉘어 있다고 해보자.

RL #3: 수평 자세 Station Keeping

RL #4: 수직 자세 Station Keeping

RL #5: 수평·수직 자세 전환

상위 RL은 해류의 방향과 크기, 추진기의 사용 가능 추력, 목표 자세, 에너지 소비량 등을 고려해서 어떤 제어기를 선택하는 것이 유리한지 학습할 수 있어.

물론 실제로 수직 자세가 유리한지는 AUV 형상과 액추에이터 구성, 유체력 특성에 따라 달라지므로 별도의 검증이 필요해.

핵심은 사람이 모든 전환 조건을 미리 정하는 것이 아니라, 상위 RL이 장기적인 임무 성능을 고려해 전환 전략을 학습한다는 점이야.

  1. 이런 구조를 연구하는 분야가 따로 있어

대표적으로 세 가지 개념을 알아두면 좋아.

① Hierarchical Reinforcement Learning (HRL)

가장 포괄적인 개념이야.

복잡한 문제를 여러 수준으로 나누고 각 수준에서 다른 정책을 학습하는 방법이지.

기존 계층 제어와 비슷하게 구성할 수 있지만, 중요한 차이가 있어.

일반적인 계층 제어에서는 상위 제어기가 생성한 목표값을 하위 제어기가 추종하도록 설계할 수 있어.

반면 네가 이야기한 HRL에서는 상위 정책이 목표값을 생성하는 대신 여러 하위 정책 중 하나를 선택하는 방식도 가능해.

참고로 계층 제어 구조와 모델 기반 여부는 별개의 구분이야. HRL에서도 모델 기반 또는 모델 프리 강화학습을 사용할 수 있어.

② Options Framework

네가 생각한 방식과 가장 직접적으로 연결되는 개념이야.

Sutton, Precup, Singh이 1999년에 발표한 연구에서 정립된 프레임워크야.

여기서는 일반적인 강화학습의 행동(Action)을 확장해서 일정 시간 동안 실행되는 행동 정책을 하나의 Option으로 정의해.

예를 들어 일반적인 RL에서는 행동이 다음과 같을 수 있어.

at​=[T1​,T2​,T3​,T4​]

각 추진기의 추력 명령을 직접 결정하는 방식이지.

반면 Options Framework에서는 상위 정책의 행동을 다음과 같이 정의할 수 있어.

atHigh​∈{Navigation,Avoidance,StationKeeping,Docking}

즉, 상위 정책 입장에서는 하나의 학습된 제어기 자체가 하나의 행동이 되는 거야.

Option은 일반적으로 실행 가능한 상태, 내부 정책, 종료 조건으로 구성돼. 따라서 단순히 매 순간 제어기를 선택하는 것뿐 아니라 언제까지 해당 제어기를 유지할지도 다룰 수 있어.

논문: Sutton et al. (1999), Between MDPs and Semi-MDPs: A Framework for Temporal Abstraction in Reinforcement Learning. (ScienceDirect)

③ Option-Critic Architecture

앞에서 설명한 Options Framework를 발전시킨 구조야.

기존에 하위 정책들을 먼저 만들어 놓는 방식뿐 아니라, 하위 정책과 종료 조건을 상위 정책과 함께 학습하는 것도 가능하게 해.

예를 들어 장애물 회피 정책을 언제 종료할지까지 학습할 수 있다는 거야.

논문: Bacon et al. (2017), The Option-Critic Architecture. (AAAI Publications)

  1. 그렇다면 실제로 어떻게 학습시킬까?

내가 네 연구 방향에서 추천하는 건 하위 모델들을 먼저 독립적으로 학습시키고, 이후 상위 RL을 학습시키는 방식이야.

처음부터 모든 모델을 동시에 학습시키는 건 훨씬 복잡해질 수 있거든.

1단계: 하위 강화학습 모델 학습

각 임무에 특화된 RL을 학습시켜.

예를 들어 경로추종 RL은 경로추종 오차를 줄이도록 학습하고, 정점유지 RL은 위치 및 자세 오차를 최소화하도록 학습하는 거야.

2단계: 하위 RL 모델 고정

학습이 끝난 하위 모델들의 파라미터를 고정해.

이렇게 하면 상위 RL을 학습하는 동안 하위 모델들의 특성이 계속 변하지 않기 때문에 학습 문제를 단순화할 수 있어.

3단계: 상위 RL 학습

상위 RL은 현재 상태를 관측하고 어떤 하위 모델을 실행할지 결정해.

여기서 상위 RL의 보상함수는 개별 제어 성능보다 전체 임무 성능에 집중할 수 있어.

예를 들면

R=w1​Rmission​−w2​Cenergy​−w3​Ccollision​−w4​Cswitching​ 각 항은 다음을 의미해.

Rmission​: 임무 수행에 따른 보상

Cenergy​: 에너지 소비에 따른 비용

Ccollision​: 충돌 위험에 따른 비용

Cswitching​: 불필요한 제어기 전환에 따른 비용

이렇게 설계하면 상위 RL은 단순히 각각의 순간에 가장 좋은 제어기를 선택하는 것이 아니라, 임무 성공률과 에너지 효율 등을 종합적으로 고려하는 정책을 학습하게 돼.

다만 실제 AUV에서는 안전을 보상함수에만 맡기는 것은 위험해. 충돌 방지나 추력 제한 등의 안전 제약은 별도로 강제하는 구조가 필요해.

  1. 실제 AUV 연구에서도 이런 접근을 사용해?

사용하고 있어.

예를 들어 2025년 12월 발표된 다음 논문이 있어.

A Hierarchical Reinforcement Learning framework with imitation learning and Bayesian Actor–Critic for distributed Unmanned Underwater Vehicle encirclement in dynamic maritime environments

이 연구에서는 UUV 임무를 여러 단계로 나누고 상위 정책이 임무 단계를 관리하며 하위 정책이 실제 제어를 수행하는 구조를 제안했어. (ScienceDirect)

또한 2026년에는 해류와 장애물이 존재하는 환경에서 상위 정책이 경로상 목표를 생성하고 하위 정책이 장애물 회피 및 추종을 담당하는 HRL 연구도 발표되었어. (ScienceDirect)

이 연구들이 모두 네가 생각한 독립적으로 학습된 여러 제어기 중 하나를 선택하는 구조와 정확히 일치하는 것은 아니지만, AUV 분야에서 계층적 RL이 실제로 연구되고 있다는 근거가 돼.

  1. 그런데 여기서 연구적으로 중요한 문제가 하나 있어

하위 RL들을 잘 학습시킨다고 해서 상위 RL까지 반드시 잘 작동하는 건 아니야.

특히 제어기 전환 과정이 중요한 연구 문제가 될 수 있어.

예를 들어 AUV가 경로추종을 수행하다가 장애물 회피 정책으로 전환한다고 해보자.

두 정책은 서로 다른 목적을 가지고 학습됐기 때문에 전환 순간의 추진기 명령이 크게 달라질 수 있어.

또한 상위 RL이 경로추종과 장애물 회피를 지나치게 빈번하게 전환하면 진동하거나 불안정한 거동이 나타날 수 있지.

따라서 다음과 같은 문제를 고려해야 해.

서로 다른 하위 정책 사이의 안정적인 전환

각 정책을 유지해야 하는 적절한 시간

하위 정책이 실패했을 때의 복구 전략

전체 임무 성능을 위한 상위 보상 설계

기존 규칙 기반 임무 관리자보다 실제로 뛰어난지에 대한 검증

특히 상위 RL이 반드시 필요한지는 중요한 질문이야. 단순한 임무라면 규칙 기반 상태기계(FSM)나 Behavior Tree로도 충분할 수 있거든.

따라서 논문에서는 강화학습 기반 정책 선택이 기존 규칙 기반 전환보다 어떤 상황에서 유리한지 보여주는 것이 중요해.

  1. 네 연구 방향과 연결한다면

나는 이 구조가 네가 관심을 가지고 있는 AUV의 운동제어, 자세제어, 강화학습을 연결하는 좋은 방법 중 하나라고 생각해.

다만 연구 방향에 따라 크게 두 가지로 나뉠 것 같아.

방향 A — 임무 수행 중심 HRL

경로추종, 장애물 회피, 정점유지, 도킹처럼 서로 다른 임무를 수행하는 하위 모델들을 만들고 상위 RL이 이를 선택하는 방식.

이 경우 연구의 핵심은 Mission Planning 및 Intelligent Decision Making에 가까워져.

방향 B — 제어 성능 중심 HRL

하나의 임무에 대해 서로 다른 환경에 특화된 제어기들을 학습시키는 방식이야.

예를 들어 AUV의 정점유지 임무 하나만을 대상으로

약한 해류에서의 정점유지 RL

강한 해류에서의 정점유지 RL

불규칙한 해류에서의 정점유지 RL

수직 자세에서의 정점유지 RL

등을 만들고 상위 RL이 상황에 맞춰 선택하는 거지.

이 경우에는 Mission Planning보다는 Adaptive Control, Robust Control, Learning-Based Control과 더 밀접해져.

물론 환경별로 정책을 분리하는 것이 단일 강건 정책보다 실제로 유리한지는 실험으로 확인해야 해.

내 생각에는

네가 제어 자체를 깊이 연구하면서 강화학습도 적극적으로 활용하고 싶다면, 처음에는 방향 B에서 시작해서 방향 A로 확장하는 접근이 좋아 보여.

예를 들어 처음에는 다양한 해류 환경에서 여러 하위 제어기를 선택하는 계층적 강화학습을 연구하고, 이후 경로추종이나 도킹 같은 임무 단위로 확장하는 거야.

이렇게 하면 하위 제어기의 성능과 안정성을 연구하면서도 장기적으로는 AUV의 자율적인 임무 수행까지 연결할 수 있어.

그런데 여기서 한 가지 더 흥미로운 점이 있어.

지금까지는 상위 RL이 어떤 하위 제어기를 사용할지 선택하는 구조만 이야기했지만, 상위 RL이 하위 제어기의 목표값까지 결정하는 구조도 가능해.

예를 들어 상위 RL이 현재 상황을 판단해 AUV의 목표 위치, 목표 자세, 목표 속도를 결정하고, 하위 RL이 그 목표를 추종하도록 학습시킬 수도 있지.

이 두 구조는 비슷해 보여도 강화학습에서 다루는 문제와 연구의 초점이 상당히 달라져.

네가 이야기한 구조는 단순히 강화학습과 모델 기반 제어를 함께 사용하는 것을 넘어서, 각 제어 방식의 장점을 살려 임무와 환경에 따라 적절한 제어기를 선택하는 구조야.

이런 접근은 크게 Hybrid Control, Supervisory Control, Switching Control, Learning-Augmented Control 등의 개념과 연결돼.

여기서 중요한 점은 상위 제어기까지 굳이 강화학습으로 만들 필요가 없다는 것이야.

중요한 건 모든 임무를 하나의 제어 방식으로 해결할 필요가 없다는 사실이지.

구조를 그려보면 다음과 같아.

이 구조에서 상위 Supervisory Controller는 강화학습일 필요가 없어.

FSM(Finite State Machine)이나 Behavior Tree 등을 이용해 충분히 구현할 수 있지.

그렇다면 상위 제어기의 역할은 제어 명령을 계산하는 것이 아니라 현재 상황에 적합한 제어 모드를 결정하는 것이 돼.

  1. 그런데 여기서 한 단계 더 발전시킬 수 있어

지금까지 우리가 이야기한 건 서로 다른 제어기를 선택해서 사용하는 방식이었잖아.

그런데 사실 모델 기반 제어와 강화학습을 결합하는 방법은 이것뿐만이 아니야.

크게 세 가지 접근을 생각할 수 있어.

① Switching Control — 제어기 선택

네가 처음 제안한 방식이야.

예를 들어

정상적인 환경 → MPC

특정 장애물 회피 상황 → RL

장애물 회피 완료 → MPC

이렇게 상황에 따라 제어기를 전환하는 거지.

이때 중요한 연구 문제는 어떤 상황에서 전환해야 하는지, 전환했을 때 안정성이 유지되는지야.

각 제어기가 개별적으로 안정적이라고 해서 제어기들을 전환하는 전체 시스템까지 안정적이라는 보장은 없어.

그래서 Switching Control에서는 전환 조건, 최소 유지 시간(Dwell Time), Lyapunov 안정성 등을 연구해.

② Residual Reinforcement Learning — 제어기 보완

이건 개인적으로 네가 한번 깊이 살펴봤으면 하는 분야야.

기존 모델 기반 제어기는 그대로 두고, RL이 모델 기반 제어기의 부족한 부분만 보완하도록 학습하는 방법이야.

예를 들어 AUV의 운동방정식이

Mν˙+C(ν)ν+D(ν)ν+g(η)=τ+τenv​ 라고 하자.

모델 기반 제어기를 설계할 때는 일반적으로 동역학 모델을 이용해 제어 입력을 계산하지.

그런데 실제 환경에서는 유체력 계수의 불확실성, 외란, 모델링 오차가 존재할 수 있어.

이때 제어 입력을 다음과 같이 구성하는 거야.

τ=τModel-based​+τRL​

여기서

τModel-based​ 는 기존 모델 기반 제어기가 계산한 명령이고,

τRL​ 은 모델 기반 제어기의 성능을 개선하기 위해 RL이 학습한 보정 명령이야.

예를 들어 모델 기반 제어기가 일정한 해류 조건에서는 정점유지를 잘 수행하지만, 모델에 반영되지 않은 외란 때문에 위치 오차가 발생한다고 하자.

RL은 이 오차를 줄이는 추가적인 제어 명령을 학습할 수 있어.

즉,

모델 기반 제어기가 기본적인 제어 성능을 담당하고 RL은 부족한 부분을 보완하는 구조지.

다만 RL의 보정 명령에도 추력 제한과 안전 제약을 적용해야 하고, RL을 추가했다고 해서 안정성이 자동으로 보장되는 것은 아니야.

실제로 이 개념을 다룬 대표적인 논문이 있어.

Residual Reinforcement Learning for Robot Control (Johannink et al., ICRA 2019). (IEEE Xplore)

③ 계층별로 서로 다른 제어 방법 사용

이 방법은 Switching Control과 조금 달라.

예를 들어 상위 계층에서 강화학습이 회피 전략을 결정하고, 하위 계층에서 모델 기반 제어기가 그 전략을 실제 움직임으로 구현하는 거야.

이 경우 RL이 직접 추진기 명령을 만들지 않아.

RL은 목표 방향이나 목표 속도를 결정하고, 실제 동역학을 고려한 제어는 MPC가 수행하는 거지.

이렇게 하면 RL의 의사결정 능력과 모델 기반 제어기의 제약조건 처리 능력을 함께 활용할 수 있어.

2025년에는 AUV 장애물 회피에서 RL과 Model Predictive Path Integral(MPPI) 제어를 결합하는 연구도 발표됐어.

Reinforcement Learning-Based Model Predictive Path Integral Control for Obstacle Avoidance of Autonomous Underwater Vehicles. (Wiley Online Library)

이때 여러 제어기의 출력 형식을 통일하거나 제어 할당 단계에서 적절히 변환하고, 모드 전환 시 명령이 급격히 바뀌지 않도록 관리해야 해.

이 구조의 장점은 새로운 임무가 추가됐을 때 기존 제어기를 모두 다시 설계하지 않고 새로운 모드를 추가할 수 있다는 점이야.

  1. 여기서 연구적으로 더 중요한 질문

나는 네가 이야기한 접근에서 왜 특정 임무에 특정 제어 방식을 적용해야 하는지를 검증하는 과정이 상당히 중요하다고 생각해.

예를 들어 장애물 회피는 RL이 잘하고 정점유지는 MPC가 잘한다고 가정하는 것만으로는 연구적 근거가 부족해.

실제로는 MPC도 장애물 회피를 상당히 잘 수행할 수 있고, RL도 정점유지를 잘 수행할 수 있으니까.

따라서 같은 AUV와 동일한 환경에서 제어기들을 비교해 보는 거야.

이렇게 비교했을 때 제어 방식마다 실제로 유리한 조건이 다르게 나타난다면, 그 결과를 바탕으로 하이브리드 제어 구조를 설계할 수 있겠지.

그리고 한 단계 더 나아가면 단순한 임무별 제어기 선택뿐 아니라 동일한 임무에서도 환경 조건에 따라 제어 방식을 선택하는 구조를 연구할 수 있어.

예를 들어 정점유지 임무 하나만 놓고 생각해 보자.

평상시에는 MPC만 사용하다가 특정 외란 조건에서는 Residual RL을 활성화하고, 학습 정책이 검증된 운용 영역을 벗어나면 안전한 모델 기반 제어기로 전환하는 방식도 연구할 수 있어.

이 경우에는 제어 모드를 결정하는 조건 자체가 핵심 연구 주제가 될 수 있지.

첫 번째 연구: 단일 임무에서 모델 기반 제어와 RL의 성능 비교

예를 들어 해류 환경에서 정점유지 임무를 수행하도록 MPC와 RL을 각각 설계하고, 두 제어기의 특성을 비교하는 거야.

두 번째 연구: Hybrid Controller 설계

앞선 실험을 통해 확인한 제어기들의 특성을 바탕으로 Switching Control이나 Residual RL을 설계해.

세 번째 연구: 다중 임무로 확장

경로추종, 장애물 회피, 정점유지, 자세 전환 등으로 임무를 확장하고 상위 Supervisory Controller가 제어 모드를 관리하도록 만드는 거지.

이렇게 진행하면 단순히 강화학습을 적용했다는 수준을 넘어서 모델 기반 제어와 학습 기반 제어의 상호보완성을 연구하는 방향으로 발전시킬 수 있어.

한 가지 구분하고 싶은 게 있어.

지금 우리가 이야기하는 제어 시스템에서는 사실 서로 다른 두 가지 연구 질문이 존재해.

A. 어떤 제어기를 사용해야 하는가? → 제어기 선택 문제 (Controller Selection)

B. 서로 다른 제어기를 어떻게 결합해야 하는가? → 제어기 융합 문제 (Controller Integration)

A는 Supervisory Control이나 Switching Control에 가깝고, B는 Residual RL이나 Learning-Augmented Control과 연결돼.

이 둘을 동시에 다룰 수도 있지만, 연구 초기에는 하나를 중심으로 접근하는 것이 문제를 명확하게 정의하는 데 유리할 거야.

특히 네가 제어 이론 자체에 무게를 두고 강화학습도 깊게 다루고 싶다면, 나는 B의 제어기 융합 문제를 먼저 살펴볼 가치가 있다고 생각해. 기존 제어기의 물리적·수학적 특성을 이용하면서 RL의 역할까지 명확하게 정의할 수 있기 때문이야.
