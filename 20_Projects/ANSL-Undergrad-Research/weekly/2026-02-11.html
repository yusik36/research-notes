주파수 응답

  • s대신 jw를 넣는 이유

  • : 시스템이 정상상태에서 사인파에 어떻게 반응하는지 알고 싶어서, 주파수 응답의 목적은 일정한 크기로 진동하는 사인파를 넣었을때 시스템의 반응을 관찰한다.
  • → s = 시그마 +jw 꼴,
  • 일정한 진동이면 진동은 감쇄하거나 진동하면 안됨 따라서 시그마 = 0 이여야 하고 s대신 jw를 넣어 응답을 관찰한다.

  • 시스템에 사인파를 넣는 이유

  • :1) 푸리에 해석을 이용하면 복잡하게 생긴 비주기적 신호와 노이즈도 사인파와 코사인파의 합으로 나타낼 수 있기 때문
    1. 선형 시불변 시스템에 사인파를 넣으면 Asin(wt) → Bsin(wt+pi) 꼴로 크기와 위상만 변하고 주파수는 변하지 않는다. 형태를 유지하기 때문에 분석이 쉬움

  • 주파수응답 그래프(ex보드선도) 에서 주파수가 커지는것(x축 증가)의 의미

  • : 저주파 → 천천히 흔듬
  • 고주파 → 빨리 흔듬
  • 시스템에 점점 더 빠르게 흔들리는 입력을 줬을때 얼마나 잘 버티는지,(gain) 반응이 얼마나 늦어지는지(phase)를 관찰
  • 시간응답 : 순간순간의 변화 분석
  • 주파수 응답 :시스템의 체급과 특성 분석

보드선도 (LPF)

    • gain plot
  • low frequency : 천천히 변하는 입력은 잘 따라감
  • band width : w0 ~ wc, gain = -3, 시스템이 제대로 반응 할 수 있는 (주파수)속도의 마지노선
  • high frequency : gain이 급격하게 떨어지며 빠르게 변하는 입력은 따라가지 못하고 무시
    • phase plot
  • 위상 그래프가 아래로 내려 가는것( ex 180 → -180) → 출력이 점점 늦어짐
  • phase lag: 주파수가 높아질수록 시스템은 입력속도를 따라가지 못하고 뒤쳐짐(위상그래프 감소) -180까지 떨어지면 시스템은 거꾸로 동작하고
  • 발산→ 제어실패
    • corner를 기준으로 저, 고주파를 구분
    • 크기선도와 위상선도를 수직으로 놓고 차단주파수와 위상 교차주파수의 위치를 비교하면 차단주파수가 위상교차주파수보다 왼쪽에 있어야 안정한 시스템
  • 직관적의미 → 게인 플롯에서 corner frequency를 기준으로 신호가 차단됨, 페이즈 플롯에서는 crossover frequency를 기준으로 시스템의 동작방향이 바뀜. crossover frequency를 지나 방향이 바뀌었는데 아직 게인 플롯에서 corner frequency를 지나지 않아 신호가 살아 있다면 시스템이 반대로 동작하며 발산. 이때 게인 플롯과 페이즈 플롯을 수직으로 놓고 corner frequency와 crossover frequency가 같은x 축에 있을때
  • 루트 로커스에서는 허수축 위에 있고 나이퀴스트 플롯에서는 (-1,0)을 지남.
  • 게인이 커진다 → 페이즈 플롯은 고정, 게인플롯 위로 평행이동 → phase margin 감소, band width 증가

  • 보드선도 (HPF)

    • gain plot
  • low frequency : 천천히 변하는 입력무시
  • band width : wc ~ wmax
  • high frequency : wc를 지난 이후 gain이 증가하며 특정 주파수에 수렴
    • phase plot
  • 고역필터는 수학적으로 미분의 성질을 갖기 때문에 미분은 위상을 90도 앞서게 만든다 → 따라서 그래프가 위에서 시작( 90 → 0)
    • 직관적으로 정리하면 HPF는 저주파가 입력되면 크기를 줄이고(게인이 낮음) 위상을 당겨 변화를 감지하려 시도한다.
  • 고주파가 입력되면 크기 그대로(ex 0db) 위상도 그대로 (0)

총정리

  • : 저역필터건 고역필터건 저주파 →고주파 방향으로 신호를 처리 할건데 높은 주파수를 다루는 태도가 다름 일반적인 상황에서 0db를 목표치(수렴해야 할 값)이라 치면 저역 통과의 경우 저주파에서 0db에 잘 수렴하다가 고주파로 갈수록 처리를 못하니까 계속 감소 하는거고 고역필터의 경우 저주파의 경우 잘 처리를 못하니까 0db아래서 빌빌거리다가 점점 다룰 수 있는 신호가 오면 상승하다가 목표치인 0db로 수렴. 이때 목표치는 게인에 따라 변함(게인을 높이면 필터가 위로 평행이동 하는 것으로 잘 이해할 수 있음)
    • low pass filter : 낮은 주파수는 막고 높은 주파수는 통과시킴
  • : 저주파에서 이득이 높다가 특정 지점 이득 감소
    • high pass filter : 낮은 주파수는 막고 높은 주파수는 통과시킴
  • : 저주파에서 이득이 낮다가 특정 지점에서 0db로 증가
    • band pass
  • 특정 구간만 통과시킴

  • 각 필터의 직관적 연결

  • 저역 통과 필터 → 기계적 명령을 수행 할 때 사용( 3차원에서 기계가 물리적으로 움직여야 하기 때문에 고주파신호를 모두 추종 할 수 없음(중력, 관성, 저항 등 때문)
  • 고역통과 필터→ 센서 등 외부에서 고주파신호를 잡아낼 때 사용
  • 이해한바 두 필터의 차이는 입력의 주체에 있지 않나? 기계의 경우 사람이 기계에서 특정행동을 이용해서 외부로 그 행동을 동작 하고 싶은것, (사람(입력)→ 기계 → 외부(출력)) 저역 필터가 일반적으로 쓰이는 상황이고 고역필터의 경우 외부신호를 센서로 감지해서 그 정보를 사용 하겠다는거니까 (외부(입)→ 센서 → 인간(출))
  • 복잡한 기계에서는 고역필터로 받은 신호를 가공해서 저역 필터로 기계로 입력(외부(입) → 센서 →인간(이 설계한 제어기) (출인 동시에 입) → 기계동작(출) 이런식.

코너 주파수랑 위상교차주파수를 알아야 여유(즉 안정도)를 판단 할 수 있음→ 일반적인 2차주파수응답은 저역 필터(적분기+ki), 고역필터(미분기+kd), 출력(kp)가 섞여 있고 각각의 대수합으로 선도가 그려질때 corner frequency와 crossover 주파수를 판단 하는법

    • corner frequency : 각성분의 크기를 대수 합해서 그래프를 그렸을때 0db를 지나는 주파수
    • crossover frequency : 적분기 →일단 -90, 플랜트 → 주파수증가에 따라 위상을 계속 깎음, 미분기 → 위상 +90
  • 이 모든 각도를 더한 최종값이 -180을 지나는 주파수

  • 각 선도들의 장단점

    1. 나이퀴스트 : 시스템의 절대안정성을 파악하는데 유리, 그래프가 꼬여 있어서 수치적설계에 불리
    1. 루트로카스 : 시간영역 응답을 예측하는데 유리, 주파수영역 특성 반영 불가
    1. 보드: P I D각 성분을 대수합으로 합치면 되서 설계가 용이함, 직관적 수정가능(ex 차단 주파수 근처에서 위상여유가 부족하다? → 고역필터 보상기 적용)

  • closed loop tf VS open loop tf

    • open loop tf : 안정성 분석, 제어기 설계. 주요 지표 → gain margin, phase margin
    • closed loop tf : 실제 추종성능, 대역폭 확인. 주요지표 → Mp,BW
  • 루트로카스,나이키스트,보드(개) → 시스템 안정도,이득여유,위상여유등 진단가능
  • 시간응답,주파수응답(내가 주파수 응답이라 알고 있던것은 폐루프전달함수의 보드선도) → 실제 시스템의 출력 개형

  • open loop tf를 closed loop 로 나타내면 꼭지가 생기는 이유

    • 폐루프 전달함수에서 분모는 1 + L(s)이다. 이때 임계주파수 를 넘었다고 가정했을때 위상은-180이 되며 L(s)는 음수가 된다. 그럼 분모가 매우 작아지므로 전체 값은 크게 뛰게된다.

  • 꼭지와 위상여유의 관계

  • : 위상여유가 크다 → L(s)가 -180 지점으로 가기전에 게인이 작아져 분모가 작아질 기회가 없음.
