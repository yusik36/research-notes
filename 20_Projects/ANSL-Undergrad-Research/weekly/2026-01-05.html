Scatter 함수를 이용해 데이터를 산점도로 나타내기

  • task2 처음에 scatter(산점도) 함수의 기능을 정확하게 이해하 지 못해서MarkerFaceAlpha의 의미를 “한개의 데이터 값을 scatter함수로 플로팅한 것을 값이 겹치는것만 알 아서 투명도를 높혔다 ” 로 이해 했지민scatter는 함수 의 그래프가 아니고 풍속-기압 간의 관계 분포를 나타 낸 것 임을 알 수 있었다. 예제의 허리케인 데이터를 예로 들면 이전까지는 독립 변수 “시간”에 대한 종속변수”기압”,“풍속”을 선으로 된 함수 그래프로 나타낸 반면 scatter는 어떤 시간에 관 측된 풍속과 기압을 ws(i), pr(i)) = i번째 관측값으로 놓 고 시간이라는 변수 없이 분포만 나타낸 것 이다. 따라 서 특정위치에 중복되는 값이 생길 수 밖에 없고, 이 중 복도(또는 편향성, 경향성)을 파악하기 위해 분포에 투 명도가 필요한 것 이다.
  • task3 scatter함수에 3번째 인자로 들어가는 크기를 변수화 하 여 크기를 다르게 플로팅 할수 있다. ex)허리케인 등급을 szcat변수에 넣어 산점도 크기에 비례한 마커가 찍힌다.

원하는 범위의 난수 행렬을 생성하는법

  • 이제0~2사이의 임의의 난수들이 생

  • task2 x = a + (b-a)*rand(m,n)가 작동하는 원 리: rand 함수는 설정한 크기의 행렬을 0에 서 1까지 임 3의의 난수로 채우기 때문 에 -1,1 사이에 균등하게 분포 하는 난 수를 만들고 싶다면 원하는 범위의 길 이를 곱해서 난수 생성 범위를 늘린다. 성되었으므로 원점을 0으로 시프트 한 다.

  • 2002년부터 2005년까지 누락된 가격을 포함하는

  • task3 변수 missingPrices를 만드십시오. 누락된 데이터를 새로 만든 벡터로 채워야 하기 때문에 데이터가 누락된 부분을 직접 확인해야 했 다. 하지만 데이터 상에서 NaN의 개수가 많거나 위치가 여기저기 퍼져 있다면 일일이 데이터를 뒤 져 찾는 것은 비 효율적 일 것 이라 생각했다. 그래 서 이 부분에서 배우진 않지만 특정 데이터값을 알고 그 값을 가진 위치를 반환하는 함수를 찾아 보니 find 함수가 있었다. find함수를 이용해 누락 된 값(Nan)을 찾기위해 idx =find(Italy == NaN) Italy(idx) = missingPrices 로 해결 할 수 있을 것 이라 생각했지만 NaN은 숫 자가 아닌 “값이 없음”을 의미 하기 때문에 값이 있는지 없는지를 판단하기 위해서는 isnan이라는 함수를 사용해야 한다는 것을 알 수 있었다. 따라 서 결론적으로 idx =find(isnan(Italy)) Italy(idx) = missing Prices 로 NaN을 갖는 값을 원하는 값으로 할당 할 수 있 었고 문제없이 실행 되는것을 볼 수 있다.
