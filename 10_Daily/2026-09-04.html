1. 논리 사슬 — 힘에서 위치까지, 그리고 닫힌 루프

사슬은 원래 고등학교 물리 두 줄이다.

① a = F / m             힘을 알면 가속도를 안다
② Δ위치 = 속도 × 시간    속도를 알면 위치를 안다

힘 → 가속도 → (적분) → 속도 → (변환·적분) → 위치

왜 방정식이 두 개로 갈라지는가 — 선형 시스템에서는 ṗ = v 라서 ①과 ② 사이에 아무 일도 없다. 6-DOF 강체에서는 이 자리가 비선형이 된다.

ν 만 봐서는 배가 어디로 가는지 알 수 없다. 같은 ν = [0,0,3]ᵀ 라도 배가 수평이면 초속 3 m로 가라앉는 중이고, 오른쪽으로 90° 누워 있으면 서쪽으로 이동 중이다. 배 안의 속도계는 두 경우 모두 똑같은 숫자를 가리킨다.

→ 그래서 통역기 J 가 ν 가 아니라 η 의 함수이고, 사슬이 한 줄로 안 닫힌다.

강의 전체가 만드는 것 — 닫힌 루프:

τ  = controller(η, η_d)
ν̇ = M⁻¹(τ − Cν − Dν − g)   KINETICS
ν  = ν + ν̇ · dt              적분
η̇ = J(η) · ν                KINEMATICS
η  = η + η̇ · dt              적분

프레임이 바뀌는 지점이 J(η) 가 필요한 지점. 제어기가 보는 목표는 지구 기준(“저 부표까지”)인데 동역학이 뱉는 속도는 배 기준(“앞으로 5”)이다.

같은 모델, 세 가지 용도 — 시뮬레이터 / 항법(IMU는 BODY, 목표는 NED) / 제어기 설계.

2. Kinematics — 좌표계 · η/ν/τ · R · T_Θ · J(η)

좌표계를 둘로 나눈 이유

{n} NED{b} BODY
축x=북(진북), y=동, z=아래x=선수, y=우현, z=아래
성격관성계로 취급배와 함께 이동·회전
담는 것위치·자세 η속도 ν, 힘 τ
선택 이유목표가 지구 기준이어야 의미가 있음관성행렬·유체력 계수·추력이 상수가 됨

그 대가로 치르는 것이 J(η) 변환식과 C(ν)ν 항이다. 공짜가 아니다. 가정 두 개 — flat earth, NED = 관성계. z축이 아래를 향해서 고도가 오르면 z가 감소하고 yaw는 위에서 봤을 때 시계방향이 +. ROS의 ENU 관례와 정반대.

상태 벡터 (SNAME 표기)

η = [x, y, z, φ, θ, ψ]ᵀ   어디에 어떤 자세로 있나 (NED)
ν = [u, v, w, p, q, r]ᵀ   얼마나 빨리 움직이나 (BODY)
τ = [X, Y, Z, K, M, N]ᵀ   무슨 힘이 걸리나 (BODY)

ν(뉴)와 v(브이)는 다른 기호. ν 는 6×1 전체, v 는 그 안의 sway 성분 하나. 대부분의 배는 underactuated → 3-DOF 수평면(surge·sway·yaw)이 랩에서 주로 쓰는 것.

회전행렬 R — 2D를 표로 포장한 것

ẋ = u cosψ − v sinψ
ẏ = u sinψ + v cosψ        계수만 뽑으면 그대로 R_z(ψ)

외우지 말고 세우는 법 — R의 각 열 = 그 좌표계의 축 단위벡터를 상대 좌표계 기준으로 적은 것. 3D 기본 회전 = 2D 표 + “회전축 자신은 통과” (지구본을 돌려도 북극점은 제자리). 합성 순서가 전부 — R^n_b = R_z(ψ)R_y(θ)R_x(φ). 스마트폰을 “눕히고 돌리기”와 “돌리고 눕히기”는 최종 자세가 다르다.

R의 성질 — 공짜로 얻는 것

  • R⁻¹ = Rᵀ — 역행렬 계산이 필요 없다. 실시간 항법에서 부담이 없는 이유
  • det R = +1, 길이 보존 — 계산 후 크기가 달라졌으면 100% 실수. 시뮬레이터 디버깅 첫 체크포인트
  • 이런 행렬들의 집합이 SO(3)
  • 읽는 법: 1열에 φ 가 없다(roll은 선수 방향을 안 바꿈) / 3행에 ψ 가 없다(연직축으로 돌아도 “연직”은 안 바뀜)

각속도 변환 T_Θ — 이번 주 최대 난관

자이로가 주는 [p,q,r] 을 [φ̇,θ̇,ψ̇] 로 바꾸는 3×3. T_Θ 없이는 자이로에서 자세를 적분해낼 방법이 아예 없다.

[p,q,r][φ̇,θ̇,ψ̇]
축 3개의 주소전부 {b} 하나{n}, {1}, {2}에 흩어짐
축끼리 직교?예아니오
측정하려면IMU 상자 하나서로 다른 세 부품에 엔코더 따로

R 이 하는 일은 같은 화살표를 다른 자로 다시 재기, T_Θ 가 하는 일은 직교하는 세 축의 성분을 비뚤어진 세 축으로 재분배. 완전히 다른 작업이므로 T_Θ 는 회전행렬일 수 없다.

T_Θ 유도와 gimbal lock

각 다이얼의 회전축을 BODY 기준으로 적어서 더한다 — roll [1,0,0], pitch [0,cosφ,−sinφ], yaw [−sinθ, cosθsinφ, cosθcosφ]. 이 방향에는 나눗셈이 하나도 없다.

T_Θ = [ 1   sinφ tanθ    cosφ tanθ  ]
      [ 0     cosφ         −sinφ    ]
      [ 0   sinφ/cosθ    cosφ/cosθ  ]

ψ 가 없고, tanθ·1/cosθ 라는 나눗셈이 생겼다 — 회전행렬이 아니라는 증거. 검산: 수평이면 T_Θ = I. 오른쪽 90° 누우면 ψ̇ = q — 배가 누우면 yaw를 만드는 건 pitch 자이로. Gimbal lock: θ = ±90° 에서 1/cos90° = 1/0. 실무에서는 quaternion.

J(η) 조립과 strapdown INS

J(η) = diag(R^n_b(Θ), T_Θ(Θ)) — 대각선에만 블록이라 선속도·각속도 변환이 안 섞인다.

자이로 [p,q,r] → T_Θ → [φ̇,θ̇,ψ̇] → ∫ → 자세 [φ,θ,ψ]
                                    ↓ 이 자세로 R을 만든다
가속도계 → R → NED 가속도 → ∫ → NED 속도 → ∫ → 위치

IMU는 BODY 값만 준다. 알고 싶은 건 전부 NED 값. 랩(ANSL) 항법 과제와 그대로 겹치는 지점.

3. Kinetics — 관찰자 · Transport theorem · Newton-Euler

문제 제기 — 미분에는 관찰자가 들어 있다

턴테이블 위에 그린 화살표변화율이유
판 위 사람이 볼 때0자(좌표축)가 화살표와 함께 도니까 눈금이 안 변한다
땅 위 사람이 볼 때≠ 0화살표가 실제로 방향을 바꾸며 돈다

미분한다 = 어떤 축을 고정으로 취급하고 그 축에 대한 성분 변화를 재는 것. 어느 축을 고정하느냐가 곧 관찰자다.

Newton이 요구하는 것 :  ⁱd/dt      ← 타협 불가
우리가 가진 것        :  ᵇd/dt      ← 센서도, 상수 M도 전부 BODY

Transport theorem (Eq.1)

ⁱd/dt(a) = ᵇd/dt(a) + ω × a

깃대 비유 — 배에 깃대를 볼트로 박으면 배 위 사람에게는 변화율 0, 해안 사람에게는 0이 아니다. 왜 하필 외적인가 — 결과가 ω 에 수직(회전축 방향으로는 안 움직임) / a 에 수직(길이가 안 변함) / 크기 |ω||a|sinφ(축에서 멀수록 빨리). 숫자로 검산: 반지름 50 m를 5 m/s로 선회 → |ω×v| = 0.5 m/s², 구심가속도 v²/R = 25/50 = 0.5 ✓. 배 안에서는 아무 가속이 안 느껴지는데도 우현으로 500 N이 필요하다.

슬라이드 58 유도 — 이번 주에 손으로 밟은 것

① 벡터를 성분 × 축으로 쓴다 ② 땅에서 미분하면 축도 미분된다(곱의 법칙) ③ 남은 문제는 i̇ = ? 하나.

i·i = 1 을 미분하면 2(i·i̇) = 0 → 길이가 안 변하는 벡터의 미분은 언제나 그 벡터에 수직.

회전i 에 대한 기여이유
roll p0i 가 회전축 자신
yaw r+(rΔt) j2D 회전 + 소각 근사
pitch q−(qΔt) k뱃머리는 위로 드는데 k 는 아래를 향함
i̇ = r j − q k = ω × i,   j̇ = p k − r i,   k̇ = q i − p j

여기서는 회전 순서를 따지지 않는다 — (I+A)(I+B) = I+A+B+AB 에서 AB 는 Δt² 이라 사라진다. 이것이 각속도가 “벡터”인 이유.

Newton-Euler — M과 C(ν)가 나오는 자리

병진 :  m v̇     +  m S(ω) v      =  f
회전 :  I_g ω̇   −  S(I_g ω) ω    =  m
        └ M ν̇ ┘   └─ C(ν)ν ─┘      └ τ ┘

C(ν)ν 는 실제 힘이 아니다. 회전하는 좌표계에서 방정식을 쓰기로 한 선택의 대가. 정정 사항 — NED 버전의 동역학 방정식은 아예 존재하지 않는다. 식은 처음부터 끝까지 BODY 하나뿐이고, NED로 가는 건 η̇ = J(η)ν 한 줄뿐이며 그건 kinematics다.

개념만 훑은 것 — S(λ)와 Inertia Dyadic

λ × a = S(λ)a, S(λ) = −S(λ)ᵀ. S(···) 가 보이면 “아, 외적이구나”로 읽으면 된다. I_g = −∫S²(r)ρdV — 각속도를 각운동량으로 바꾸는 환율표. p = mv 의 m 자리. 대각선 = 관성모멘트, 비대각선 = 관성곱 = 커플링(세탁기 탈수). 배는 좌우대칭이라 I_xy ≈ I_yz ≈ 0 이지만 위아래로는 비대칭이라 I_xz 는 실선에서 거의 0이 아니다 → roll–yaw 커플링. 대칭 + 양정치 → 역행렬이 항상 존재 → ν̇ = M⁻¹(…) 가 언제나 풀린다.
